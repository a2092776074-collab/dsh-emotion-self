# dsh-emotion-self

给你的助手一份**语气档案**：写评论、私信、群聊、文档之前先过一遍。
它管的是"这话像不像人说的、场合对不对"，不管事实对错。

## 它有什么

| 部件 | 干什么 |
|---|---|
| `emotion_check` 工具 | 一段草稿 → 改写 + 问题清单（场合、机器腔、忌讳、否决） |
| 语气档案 `lib/emotion/self/profile.js` | 称呼、句长、句尾小尾巴、忌讳词、各场合松紧 |
| 判定 / 调制 / 否决 / 矫正 | 底层四件套，可以单独当库用 |

## 装法

```yaml
# 插件根目录已有 cordis.patch.yml，放进 profile 后会自动注册
- insert:
    - id: emotion-self
      name: dsh-emotion-self
```

装好之后，模型会多一个工具：

```
emotion_check({ text: "综上所述，建议您优先考虑该方案。", scene: "comment" })
```

返回改写版本 + 问题清单。

## 语气档案怎么改

打开 `lib/emotion/self/profile.js`，它就是一份模板：

```js
export const VOICE = {
  who: '你的助手',
  address: { owner: ['用户'], self: ['我'] },
  baseline: { sentence: '短句为主，一句一个意思', ... },
  forbidden: ['本鱼', '作为 AI'],
  scenes: {
    comment: { intensity: 0.8, playfulness: 0.7, formality: 0.25, maxLength: 120 },
    ...
  },
}
```

**改了之后不用重启插件**——下次调用工具就读新档案。

## 限制由你定

否决规则（比如"别说某个称谓"）默认**一条都不拦**，写在 `数据/情绪配置.json` 才生效：

```json
{ "veto": { "block": ["owner"], "warn": ["sycophant"] } }
```

没这个文件 = 零拦截。

## 实测数据（别指望它做不到的事）

- 1403 组「AI 味 vs 人话」对照：AI 味一侧约 21% 被改到，人话一侧 **0% 误伤**，输出碎片 **0**
- 31 条真实短评论回放：**0 命中**——短句本来就没机器腔，这条是给长文用的
- 事实问答无增益（540 题实测 +1，噪声内）

**结论：评论可以不用，文档最该用。**

## 安全阀

矫正器是"删句式"的，删过头会把句子删成碎片。内置三道回退：

1. 重复标点清理
2. 小句级回退（某句内容掉 40% 以上就只回退这一句）
3. 整句兜底（整段掉 40% 以上或删成纯标点，整句不动）

**宁可不动，也不改坏。**
