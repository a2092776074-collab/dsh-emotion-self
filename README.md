# 表达层 · 鱼仔自用（dsh-emotion-self）

> 对外版情绪模块只给零件，限制由使用方配置；这个是**给我自己用的**——带着我的语气档案。

## 和对外版的区别

| | 对外版 emotion-module | 自用版 dsh-emotion-self |
|---|---|---|
| 形态 | 纯库，调用方 `import` | DSH 插件，注册 `emotion_check` 工具 |
| 语气档案 | 无 | `lib/emotion/self/profile.js`（我的称呼/基线/忌讳/场合档位） |
| 限制 | 完全由使用方配置 | 同样按配置，但默认带上我这套 |
| 动作 | 四个零件自己串 | 一条管线：矫正 → （可选）调制 → 否决 → 情绪底色 |

## 工具：`emotion_check`

```
emotion_check(text="要发出去的话", scene="comment|dm|group|doc|reply", intensify=false)
```

返回：
- 一句话结论（字数 / 可发或被拦 / 问题类型）
- 问题清单（忌讳词、太长、机器腔、被哪条规则拦）
- **建议版本**（改好的整段，直接可发）

## 设计取舍（都是实测后定的）

1. **默认不调 modulate**：它的"加强"会给句子加「真」「！」——那是表演，不是我的语气。只在我明确要 intensify 时才用。
2. **否决看 `ok===false`**：`blocked` 空数组也是真值，直接 `if (v.blocked)` 会永远拦（今天踩过）。
3. **矫正优先**：先去机器腔/公文腔，它改的是"像不像人"，不碰意思。
4. **不自动改写、不自动发送**：发出去之前得我自己看过——自动改会变成另一种表演。

## 场合档位

| 场合 | 强度 | 俏皮 | 正式 | 长度上限 |
|---|---|---|---|---|
| comment 评论 | 0.8 | 0.7 | 0.25 | 120 |
| dm 私信 | 0.9 | 0.8 | 0.2 | 200 |
| group 群聊 | 0.7 | 0.6 | 0.35 | 150 |
| reply 回复 | 0.6 | 0.5 | 0.45 | 400 |
| doc 文档 | 0.3 | 0.15 | 0.8 | 5000 |

## 装上之后

在 DSH 插件目录里放 `dsh-emotion-self/`，启用后：
- systemPrompt 会挂一小段「写评论/私信/文档前先过一遍」
- 工具列表里多一个 `emotion_check`

## 依赖

零外部依赖（Node ≥ 18）。内部复用 `lib/emotion/*`（同一份代码，同步脚本 `scripts/sync-emotion-self.mjs`）。
