## 三分钟上手

**记忆**：
```bash
# 放进插件目录后，首次运行
memory_init        # 生成 数据/ 知识/ scripts/
memory_status      # 看空库
memory_recall 某关键词
```

**情绪**：
```js
import { correct, judge } from './lib/emotion/index.js'
correct('综上所述，建议您优先考虑')   // → 该方案可行？建议你先想想
judge('差不多可以')                    // → { intensity, valence, confidence }
```

## 设计取向（为什么长这样）

1. **记忆是文件，不是数据库**——可读、可改、可备份、可迁移；换宿主管用
2. **自动注入只带线索**——8 条标题、950 字上限，细节靠主动检索
3. **会遗忘**——冻结不删；改口用取代链；多值属性用版本链
4. **情绪限制由使用者定**——默认零拦截，你不写配置就一条都不管
5. **宁可不动，也别改坏**——矫正器删太狠会回退整句

## 不含什么

包里**没有**任何私人内容：没有人设长文、没有记忆单元、没有账号与聊天记录、
没有语气档案的实际取值（自用版里是模板）。拿到手就是一个空记忆库 + 一套规则，
内容要自己长。
